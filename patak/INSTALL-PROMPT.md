התקן לי את ערכת "פתק" ל-Claude Code. היא מוסיפה שני דברים, ברמת המשתמש (לכל הפרויקטים):
1. סקיל בשם "פתק" שמעדכן קובץ STATE.md בתיקיית הפרויקט בסוף סשן.
2. hook בפתיחת סשן שטוען את STATE.md לבד, אם הוא קיים בתיקייה. גם אחרי דחיסה של השיחה.

בצע בדיוק את הצעדים האלה:

צעד 1 - הסקיל. צור את הקובץ ~/.claude/skills/פתק/SKILL.md עם התוכן הזה בדיוק, בלי לשנות אף תו:
<<<SKILL
---
name: פתק
description: מעדכן את STATE.md, הפתק של הפרויקט, כדי שהסשן הבא ימשיך בדיוק מאיפה שעצרנו. להפעיל כשהמשתמש אומר "פתק" או "סוגרים להיום".
---

# פתק - מעדכן את STATE.md

המטרה: שסשן חדש לגמרי יוכל להמשיך את העבודה רק מהקובץ הזה, בלי השיחה של היום.

1. קרא את `STATE.md` בתיקיית הפרויקט. אם הוא לא קיים, צור אותו בדיוק במבנה הזה:
   `# STATE - הפתק של הפרויקט`, שורת `עודכן:`, ואז ארבעה סעיפים: `## איפה אנחנו`, `## מה נגמר`, `## מה הבא`, `## מה הוחלט ולמה`.
2. עדכן לפי מה שקרה **בסשן הזה בלבד**:
   - **איפה אנחנו:** משפט אחד, מחליף את הקודם.
   - **מה נגמר:** הוסף רק מה שהושלם באמת (ואם נבדק, כתוב איך). השאר עד 10 פריטים אחרונים.
   - **מה הבא:** 1 עד 3 צעדים. הראשון ספציפי מספיק כדי להתחיל בו בלי לשאול שאלות.
   - **מה הוחלט ולמה:** הוסף החלטות חדשות עם הסיבה. אל תמחק החלטות ישנות; החלטה שהתהפכה מסמנים "בוטל:" עם הסיבה.
3. עדכן את שורת `עודכן:` לתאריך של היום.
4. אל תמציא. משהו לא ברור (נגמר או לא? מה הוחלט?) - שאל לפני שכותבים.
5. שמור את הקובץ קצר: עד 60 שורות.
6. בסוף: הצג את ארבעת הסעיפים בקצרה, ואמור: "הפתק מעודכן. בסשן הבא פשוט תגידו: איפה עצרנו?"
SKILL>>>

צעד 2 - ה-hook. הקובץ הוא ~/.claude/settings.json.
- אם הוא קיים: קודם גבה אותו ל-~/.claude/settings.json.bak-patak. אחר כך הוסף את האובייקט הבא כאיבר חדש בסוף המערך hooks.SessionStart (צור את hooks ו-SessionStart אם הם לא קיימים). אל תשנה, תמחק או תסדר מחדש שום דבר אחר בקובץ.
- אם הוא לא קיים: צור אותו עם {"hooks": {"SessionStart": [האובייקט]}}.
- אם כבר יש ב-SessionStart hook שהפקודה שלו מכילה "STATE.md": אל תוסיף שוב.
- את הגיבוי עשה עם פקודת cp אחת. את העריכה עצמה עשה בכלי עריכת הקבצים (Edit), לא בפקודות shell או python.
האובייקט:
{
  "matcher": "startup|resume|clear|compact",
  "hooks": [
    {
      "type": "command",
      "command": "f=\"$CLAUDE_PROJECT_DIR/STATE.md\"; [ -f \"$f\" ] && { echo \"הפתק של הפרויקט (STATE.md), מהסשן הקודם. קרא אותו לפני שממשיכים:\"; cat \"$f\"; }; exit 0"
    }
  ]
}

צעד 3 - בדיקה. ודא שהקובץ ~/.claude/settings.json הוא JSON תקין, ושמספר ה-hooks בכל אירוע אחר נשאר כמו לפני. אם משהו לא תקין, שחזר מהגיבוי ותגיד לי.

צעד 4 - סיכום. תגיד לי בשתי שורות מה הותקן, ושמעכשיו: בסוף סשן כותבים /פתק, ובסשן הבא פשוט שואלים "איפה עצרנו?".
